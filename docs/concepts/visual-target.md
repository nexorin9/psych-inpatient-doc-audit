# 视觉目标卡 · 精神科住院文书审查系统

> 本文件是**结构化视觉目标**（非图片）。运行环境无图像生成能力，故不放置任何图片文件；
> `docs/screenshots/` 下的真实运行截图由 Phase 4 采集，二者构成「目标 ↔ 实测」对照。

**画面类型**：**桌面窗口**（PySide6 主窗口 + 系统托盘常驻），非终端、非 Web 控制台。
标签页：「文书包审查」/「归档核齐」。

---

## 1. 起始态（空窗口）

- 中央一块虚线拖放区，文案「把住院文书包拖进来 / 选文件夹」。
- 左栏住院条目列表为空（显示占位文案「尚未载入文书包」）。
- 右栏内容区空白，仅显示一行提示「载入后在此列出问题清单」。
- 底栏运行摘要：`重跑 0 件 · 跳过 0 件 · 规则集 ———`。
- 托盘图标静默，无角标。

## 2. 首个可用瞬间（载入一份含违规的文书包）

- 左栏一列住院条目：`脱敏别名 · 科室 · 缺件数徽标`（徽标红底白字，如 `缺 3`）。
- 右栏为问题清单，每条一行三段式：

  ```
  QC-PSY-04   约束知情同意缺失   住院记录 · 第 3 件 · 第 2 段
              依据：约束开始时间早于签署时间
  ```

- 正文卡片按段落序列渲染，**违规段落整段浅红底**（`#D64545` 低饱和版，约 12% 透明度），
  段首标规则码；卡片下方固定一行「依据：……」灰字。
- 可自动补写的条目在右侧亮起蓝色按钮「预览补写」；`FixAvailability::None` 的条目
  **只给依据、不给按钮**（这是本产品的一等状态，不是缺功能）。
- 底栏刷新：`重跑 12 件 · 跳过 0 件 · 规则集 a3f9c1e2`。

## 3. 成形态（常驻 + 归档核齐）

- 托盘图标带角标数字（本病区待提交且不达标份数），与窗口内状态同源。
- 切到「归档核齐」标签：同一份住院变为依赖图视图。
  - 节点四态配色：缺件 `#D64545` / 正常 `#2DA44E` / ambiguous 灰 `#8B949E`（带角标）/
    被连带阻塞 橙 `#E3A008`。
  - 阻塞边加粗，普通边 1px 灰。
- 右侧栏：欠件天数 + 「这条卡住了谁」「这件在等谁」两份方向相反的清单，可切换。
- 底部一行「一键发缺件待办」按钮；已发项按钮置灰并显示「已于 T 时刻由 X 发出」。
- 底栏常驻运行摘要：`重跑 1 件 · 跳过 199 件 · 规则集 a3f9c1e2`。

## 视觉语言

| 元素 | 取值 | 说明 |
|------|------|------|
| 主色（可操作） | `#1F6FEB` | 按钮、可点击行、补写预览高亮 |
| 警示（缺件 / 违规） | `#D64545` | 缺件徽标、违规段落底、阻塞边 |
| 达标 | `#2DA44E` | 完整件节点、已收状态 |
| 底色 | `#F6F8FA` | 窗口底、右栏卡片底 |
| 卡片边框 | `#D0D7DE` | 1px，圆角 4px |
| 次要文字 | `#57606A` | 依据行、提示语 |

- **字体族**：码与规则集版本哈希用等宽（`Menlo / Consolas / monospace`）；
  正文用系统无衬线（`PingFang SC / Microsoft YaHei`）；依据行 12px。
- **信息层级**：`问题码 > 段落定位 > 依据文案` —— 码最醒目（等宽 + 主色/警示色），
  定位次之（次要色），依据最小最淡。
- **留白密度**：中等偏松；列表行高 32px；问题条目之间 8px 分隔。
- **禁用态**：`FixAvailability::None` 条目的按钮位置留空但保留 32px 行高，
  避免列表抖动（体现「只给依据不给按钮」）。

## 必须可达的约束

- 只用 Qt 现有控件（`QTabWidget` / `QListWidget` / `QTextEdit` / `QGraphicsView` /
  `QSystemTrayIcon`）+ QSS 样式表做出以上效果。
- **不画** WebGL / 3D 场景、不画动画曲线图、不画设计稿级别的插画。
- 托盘角标用 `QSystemTrayIcon` 原生支持，不自绘。
- `docs/screenshots/` 下的图必须是**真实运行界面抓取**（`QScreen.grabWindow()`），
  不得用概念图或设计稿冒充。
